## 关于逐光英语

逐光英语面向已经具备基础英语能力、希望进一步突破瓶颈的学习者。我们以真实学习目标为起点，将备考路径、能力训练和个性化复盘组织成清晰、持续、可执行的学习系统。

这里不只是资料的集合。我们更关注学习者为什么出错、下一步应该练什么，以及怎样把一次练习真正转化为长期能力。

## 五条学习路径

### 中考英语

夯实词汇、语法和语篇能力，把“读得懂”逐步转化为“写得准、说得清”。

### 高考英语

面向复杂语篇、语言运用和书面表达，建立稳定的限时训练与真题复盘体系。

### 考研英语

围绕大纲词汇、长难句和真题逻辑展开训练，并针对英语一、英语二制定不同路径。

### 雅思 IELTS

从目标分数出发，协同提升听、说、读、写四项能力，让每次训练都对应真实评分要求。

### 托福 TOEFL

适配 2026 年新版 TOEFL iBT，围绕学术场景下的阅读、听力、口语与写作建立训练闭环。

每个模块的首页卡片与详情页都提供独立的官网信息直达入口，考试政策、题型与报名信息以官方最新公告为准。

## 私人学习档案

每位接受个性化辅导的学生都拥有独立学习空间，用于沉淀：

- 阶段能力诊断
- 课堂记录与学习反馈
- 薄弱项和错题复盘
- 高频词块与重点笔记
- 个性化训练计划
- 阶段进步与能力变化

私人档案需要学生本人登录后查看。账号之间相互隔离，学生数据不会作为公开学习资料展示。

## 我们相信

英语提升不是无止境地刷题，而是不断完成一个更有效的循环：

**确认目标 → 定位弱项 → 专项训练 → 复盘订正 → 回到实战**

保持优势，把时间投向真正影响进步的短板。练得不必更多，但每一次都应该更有效。
